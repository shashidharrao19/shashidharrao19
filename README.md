<summary><b>Note: if any card above shows a broken image or "Failed to retrieve" error</b></summary>
<br/>

**Why this happens:** these cards run on free, shared public servers — not something specific to this profile. GitHub allows 5,000 API requests per hour per server, and each of these public servers is used by hundreds of thousands of GitHub profiles. Once that limit is hit, the card breaks for everyone until it resets an hour later. This is a known, ongoing problem, documented through 2025 and into 2026 — not a one-time bug.

**The fix: stop depending on the shared server, generate the cards yourself.**

The workflow file below (`update-cards.yml`) runs inside this repo using GitHub Actions. It calls the GitHub API using this repo's own token — a separate 5,000/hour quota that nothing else can exhaust — and writes the result as a plain SVG file into this repo once a day. That file is then referenced directly, with no live server involved at request time.

Setup:
1. In the profile repo (`shashidharrao19/shashidharrao19`), add the file at `.github/workflows/update-cards.yml`
2. Push it — it runs on a daily schedule, or can be triggered manually from the Actions tab
3. Replace the image URLs above with the generated file paths, e.g. `./profile/stats.svg`

This is effectively running a private version of the same tool, with no shared rate limit.
